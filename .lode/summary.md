# Summary

Rewrite of [Structurizr Site Generatr](https://github.com/avisi-cloud/structurizr-site-generatr) (Kotlin/JVM static-site generator for C4 models) as a new system with exactly three locked decisions: the UI is a SPA (no static HTML generation), the SPA reads Structurizr workspace JSON from the web server, and the CLI is written in Rust. Every other architectural choice — input contract, diagram layout, serving model, SPA stack, feature sequencing — is deliberately open and tracked in [architecture/open-questions.md](architecture/open-questions.md). The architecture is being built incrementally in chat before any code exists; this repo is currently empty. Inventory of the original tool lives in [background/original-tool.md](background/original-tool.md); research on the surrounding Structurizr ecosystem in [background/structurizr-ecosystem.md](background/structurizr-ecosystem.md).
