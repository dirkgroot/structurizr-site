# Summary

Rewrite of [Structurizr Site Generatr](https://github.com/avisi-cloud/structurizr-site-generatr) (Kotlin/JVM static-site generator for C4 models) as a SPA + workspace-JSON-over-HTTP system with a Rust CLI. The walking skeleton works: `structurizr-site generate` shells out to the `structurizr` CLI for the workspace JSON export and copies the embedded Vite/React SPA into the output directory; the SPA renders workspace and software-system pages through client-side routing (hash URLs by default, clean path URLs opt-in). Remaining forks — diagram layout, serving model, parity order — are tracked in [architecture/open-questions.md](architecture/open-questions.md). Inventory of the original tool lives in [background/original-tool.md](background/original-tool.md); research on the surrounding Structurizr ecosystem in [background/structurizr-ecosystem.md](background/structurizr-ecosystem.md).
